## 4. Content that earns links naturally

Publish one of these per month; each is linkable on its own merit:

1. **Browser formatter benchmark.** Measure parse+format time for 1 KB, 10 KB,
   100 KB inputs per language. Publish raw data. Nobody else has this.
2. **"Why dart format always adds trailing commas"** explainer. Already
   drafted inside the site; promote as a standalone post.
3. **Roblox Lua style survey.** Sample 200 popular Roblox models, report
   indentation stats. Original data earns citations.
4. **WASM formatter round-up.** Compare @wasm-fmt engines: speed, size,
   correctness. The site already depends on them.
